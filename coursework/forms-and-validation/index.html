Two sources, two homework tasks.

The study guide assigns a student registration form. The PDF assigns a contact form for your personal site. Both are completed here. Every exercise is a self-contained HTML file with embedded CSS and JavaScript.

These are browser validation demos. They do not send messages, create accounts or store passwords.

Practice checklist

Submit empty fields. Try an eight-digit ID, a seven-character password and an out-of-range age. Correct each value. Test the terms checkbox, slider and keyboard focus.

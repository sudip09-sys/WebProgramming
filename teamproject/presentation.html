MEMORY MATCH / Game configuration05 / 12

Modes and Difficulty

  1. Warm-up: 6 pairs; Focused: 8 pairs; Expert: 12 pairs.
  2. Timed: finish before the countdown reaches zero.
  3. Practice: play without a countdown.
  4. Duel: share one device; the most pairs wins.

In Duel, a successful match keeps the turn. A mismatch passes it. Most pairs wins.

MEMORY MATCH / Scoring model06 / 12

Scoring and Hints

  1. Consecutive rewards: 100, 125, 150, 175, then 200 points.
  2. Example: two consecutive matches total 225 points.
  3. A mismatch resets the streak.
  4. Peek: one-second reveal, one hint used, 50-point penalty.

Points never fall below zero. Peek requires no open card or active reveal. Duel victory uses pair counts.

MEMORY MATCH / System architecture07 / 12

Code Organisation

  1. index.html: controls, scoreboard and board structure.
  2. style.css: layout, card appearance and feedback.
  3. engine.mjs: game data and rules, independent of the DOM.
  4. game.mjs: receive clicks, call the engine, render updates.

Keeping the engine independent of the DOM allows Node to test the rules directly.

MEMORY MATCH / Matching algorithm08 / 12

How a Matching Attempt Works

  1. Create two copies of each symbol; shuffle with Fisher–Yates.
  2. Ignore matched cards, repeated clicks and locked selections.
  3. Two valid selections count as one move; compare symbols.
  4. Match: keep cards visible. Mismatch: lock, wait 800 ms, settle.

Example: star + star stays visible; star + heart closes. In Duel, settle() also passes the turn.

MEMORY MATCH / State management09 / 12

Game States

  1. Preview: show symbols and block card selections.
  2. Playing: accept valid selections.
  3. Mismatch / Hint: temporarily block new selections.
  4. Won / Lost: stop the round and reject further flips.

If time expires during a mismatch, settle() cannot change the lost phase back to playing.

MEMORY MATCH / Timing and accessibility10 / 12

Timing and Accessibility

  1. performance.now(): measure actual elapsed time.
  2. Update the countdown when tab visibility changes.
  3. Restart clears the interval and pending reveal timeout.
  4. Tab + Enter operate cards; reduced motion disables animation.

The timed countdown begins after preview and continues during hint and mismatch reveals.

02 / The project

A familiar game with more decisions

Find every pair while managing time, hints, and consecutive matches.

HTML structures the interface. CSS displays card states. JavaScript controls each round.

03 / Ways to play

One board, three modes

Timed: clear the board before the countdown ends.
Practice: learn the rules without a countdown.
Duel: two players share one device. Most matched pairs wins.

A correct match keeps the duel turn. A mismatch passes it.

04 / Difficulty

A smaller board makes a clearer first demo

Warm-up: 6 pairs · 120 seconds · 3 hints
Focused: 8 pairs · 100 seconds · 2 hints
Expert: 12 pairs · 90 seconds · 1 hint

Every round begins with a three-second preview. Only timed mode uses the countdown.

05 / Code structure

Game rules stay separate from the interface

index.html + style.css: controls, board and presentation.
engine.mjs: cards, phases, scoring and rules.
game.mjs: clicks, rendering and elapsed time.

engine.test.mjs checks the rules without opening a browser.

06 / One turn

Two selections trigger one decision

First card: remember its index.
Second card: compare the two symbols.
Match: keep the pair visible and update the score.
Mismatch: block another selection, then hide both cards after 800 ms.

The engine ignores a matched card or a repeated click on the same open card.

07 / Score and hints

Consecutive matches earn more points

Match rewards: 100, 125, 150, 175, then 200 points.
A mismatch resets the streak.
A hint reveals the board for one second and costs 50 points.

Points never drop below zero. Duel victory uses matched pairs, not the points total.

08 / Demo and validation

A short round shows the core behavior

Demo: preview, match, mismatch, hint, then a duel turn change.

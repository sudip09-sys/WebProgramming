Record and combine the video

  1. Record slides in fullscreen with clear microphone audio. Include a camera view if your professor requires it.
  2. Either record all four speakers in one session or record four separate clips using the same slide size and recording resolution.
  3. During slide 4, Sudip records the actual game: preview, match, mismatch, hint and duel turn change. Return to slide 5 for modes and difficulty, followed by scoring on slide 6. Abinash explains the introductory material on slides 1–3 and does not need to operate the game.
  4. Combine separate clips in speaker order. Trim setup time and long pauses while keeping the explanation and demonstration clear.
  5. Export one MP4 and watch the full exported file to check audio, slide readability and the gameplay demonstration.

Local setup

Download and extract the repository. In its root directory run python -m http.server 8000, then open http://localhost:8000/teamproject/. VS Code Live Server is another option. Use an HTTP server because the game imports JavaScript modules.

Demo sequence

  1. Select Warm-up and Practice. Start the round and explain the three-second preview.
  2. Choose a pair you remember. Show the updated pair count and points.
  3. Select two different symbols. Wait for them to close before selecting again.
  4. With no open cards, use Peek and explain the hint count and penalty.
  5. Choose Duel and restart. Show that a mismatch changes the active player.
  6. Finish by explaining that timed mode uses elapsed time, including time spent in a background tab.

Submission guide

Memory Match · Sudip, Sondor, Eric and Abinash

One project, four presenters, one clear demonstration.

Suggested presentation plan

MemberSlidesSpeaking focus
Sudip1–2Introduction and project purpose

Allow roughly two minutes per speaker plus a two-to-four-minute demonstration. These are suggested speaking assignments, not a record of who implemented each feature.

Submission checklist

  1. Confirm the professor's upload format and deadline.
  2. Open the presentation and choose Print / PDF. Save all eight slides as a PDF in landscape orientation.
  3. Print the report and speaking scripts to PDF if required.
  4. Download the repository ZIP. Keep the entire teamproject folder together.
  5. Include the live game and repository links below.
  6. Replace the contribution placeholders in the report with your actual work. Add student IDs only if required.
  7. Rehearse once on the computer you will use. Keep a local HTTP server copy available.

Local setup

Download and extract the repository. In its root directory run python -m http.server 8000, then open http://localhost:8000/teamproject/. VS Code Live Server is another option. Use an HTTP server because the game imports JavaScript modules.

Demo sequence

  1. Select Warm-up and Practice. Start the round and explain the three-second preview.
  2. Choose a pair you remember. Show the updated pair count and points.
  3. Select two different symbols. Wait for them to close before selecting again.
  4. With no open cards, use Peek and explain the hint count and penalty.
  5. Choose Duel and restart. Show that a mismatch changes the active player.
  6. Finish by explaining that timed mode uses elapsed time, including time spent in a background tab.

Before presenting

Read the code you are explaining. Describe what the project does, acknowledge assistance when required by course policy, and do not claim that a proposed role is a completed contribution.

1. Problem and purpose

The instructor requested a visible skip link on the first Tab press and a way to reach the main content without traversing every navigation link. The portfolio previously placed its return navigation before the skip link. Several pages also lacked an explicitly focusable main-content target.

This revision makes the skip link the first keyboard stop and transfers keyboard focus to the main landmark when activated. The shared behavior covers the main homepage, Week 10 hub, portfolio, Book Search and Git exercise.

3. Keyboard test procedure

  1. Open a page freshly, with focus in the page.
  2. Press Tab: “Skip to the main content” becomes visible and focused.
  3. Press Enter: focus moves to the main-content landmark.
  4. Press Tab: focus continues to the first available link or control inside the main content, bypassing the navigation above it.

Tab moves between controls; Enter activates a link. The implementation retains this standard keyboard behavior rather than making Tab automatically activate the skip link.

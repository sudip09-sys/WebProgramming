Seoul weather

Request current temperature and wind speed from Open-Meteo. The result includes the observation time and units returned by the API.

Seoul · 37.5° N, 127° E

Read the core code
const url = "https://api.open-meteo.com/v1/forecast?latitude=37.5&longitude=127&current=temperature_2m,wind_speed_10m&timezone=Asia%2FSeoul";
const data = await getJSON(url);
console.log(data.current.temperature_2m);

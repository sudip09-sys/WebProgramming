# Sudip Sah — Portfolio

## How to run
1. Open this folder in VS Code.
2. Open `index.html`.
3. Use Live Server, or simply open `index.html` in a browser.

## Files
- `index.html` — page structure/content
- `style.css` — complete responsive styling
- `script.js` — interactive mini JavaScript lab

## Design direction
This site is intentionally built around the principles in the uploaded "30 reasons your site looks vibecoded" reference:
- no rainbow/hero gradients
- no neon palette
- no emoji UI
- no excessive rounded cards
- no fake testimonials
- no fake pricing section
- no decorative icon overload
- no meaningless skeleton loaders
- restrained shadows
- real interactive demo
- clear typography and spacing
- responsive layout
